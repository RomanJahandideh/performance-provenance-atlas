# Presentation Controls

**Scrolling is the storyteller.** The camera travels the atlas, the drawings run
themselves (constraints parse, planes rise, floors recover, seed tracks race,
the spine lights up), and large unboxed text fades through — nothing needs a
click, nothing scrolls inside a panel, and there is no timer.

Press `?` in the app for this table at any time.

| Key | Action |
|---|---|
| scroll / trackpad | advance the story (also backwards) |
| `↓` `↑` `←` `→` `Space` / `Shift+Space` | scroll the story forward / back |
| `PageDown` / `PageUp` | next / previous scene |
| `Home` / `End` | first / last main scene |
| `1`–`9`, `0` | jump to a scene (0 = Why GenEnv) |
| progress rail (bottom) | click any stop; the active stop fills with scene progress |
| `#scene-<id>` URL hash | deep-links a scene; follows as you move |
| `F` | full screen |
| `N` | speaker notes dock |
| `S` or `C` | sources + evidence drawer |
| `L` | map legend |
| `M` | chapter map |
| `R` | restart from the opening |
| `X` | reduced-motion toggle (also honours the OS setting) |
| `Esc` | close any panel |

## What the scroll shows, scene by scene

1. **Opening** — the full atlas; title as a site designation; the route explained.
2. **Trajectory** — the camera climbs Tabriz → Istanbul → SFU; award boards light; one constant question.
3. **Foundation** — the eCAADe transparency sweep runs live and the “nearer” arrow flips at 60%; the ISS halo pulses beside the numeric chip; the BioTerrarium loop streams.
4. **Massing Generator** — eight constraints parse row by row; setback planes rise; the envelope extrudes; the parcel turns irregular; the block classifies; the review stamps.
5. **Zoning Assistant** — the pipeline flows; a grounded answer quotes its clause; the laneway case severs the pipeline at **NOT COVERED**; the site check computes 162.6 m² and flips 1 → 2 floors.
6. **View Corridor** — the ceiling draws; the flat-cap building rises (10 fl · 18,360 m²); floor-by-floor trimming recovers to 18 fl · 25,608 m² (+39.5%) with live counters; the footprint sweeps 0–90°.
7. **Massing Agents** — the council assembles; agent paths pulse; 5+5 seed tracks race the 95% line (4/5 vs 1/5); the Pareto front settles; the verdict stamps **NOT CONFIRMED** beside the supported findings.
8. **Synthesis** — the six-stage chain draws over the four parcels.
9. **PhD** — the provenance spine lights link by link, each showing what the record keeps (real corridor revision, labelled conceptual).
10. **Why GenEnv** — the attributed territory reveals; the provisional connector reaches in.
11. **Conversation** — the full atlas returns with three questions.
A. **Appendix** — verified links, outside the main route.
