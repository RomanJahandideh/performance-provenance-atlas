# Presentation Controls

Press `?` in the app for this table at any time.

## Navigation

| Key | Action |
|---|---|
| `↓` `→` `Space` | Next step within the scene, then next scene |
| `↑` `←` `Shift+Space` | Previous step / scene |
| `PageDown` / `PageUp` | Next / previous scene (skips steps) |
| `Home` / `End` | First / last main scene |
| `1`–`9`, `0` | Jump to scene (0 = scene 10, Why GenEnv) |
| mouse / trackpad scroll | Normal scrolling between scenes (no hijack) |
| progress rail (bottom) | Click any stop to jump; hover shows the title |
| `#scene-<id>` URL hash | Deep-links any scene (e.g. `#scene-ema`); updates as you move |

## Presenter tools

| Key | Action |
|---|---|
| `F` | Full screen |
| `N` | Speaker notes dock (script + next scene + step label) |
| `S` or `C` | Sources + evidence drawer for the current scene |
| `L` | Map legend (status drawing language, colours, axes) |
| `M` | Chapter map overlay (all scenes + targets) |
| `T` | Start / pause the timer (auto-starts on first forward navigation) |
| `R` | Restart presentation + timer |
| `D` or `E` | Presentation ↔ explore mode |
| `X` | Reduced-motion toggle (also honours the OS setting) |
| `Esc` | Close any open panel / sheet |

## Timer

HUD shows `elapsed / 17:30` plus a drift readout versus the cumulative target at the start of
the current scene: cyan `−` = ahead, orange `+` = behind. The appendix scene is outside the
timed route.

## Explore mode

Drag to pan, wheel to zoom (to the cursor), click the mini-map to recentre, click any parcel or
award structure to open its sheet, filter by status with the top bar. Presentation scrolling is
suspended until you leave explore mode.
