# Presentation Controls

**One scroll = one step. Exactly 20 steps.** The page itself never scrolls. Each wheel gesture,
trackpad swipe, or key press moves exactly one step. Arriving at a step flies the map camera and
plays that step's drawing automatically, in about three seconds. You never need to keep
scrolling to see something.

| Input | Action |
|---|---|
| one wheel gesture / trackpad swipe / touch swipe | next or previous step |
| `↓` `→` `Space` `PageDown` | next step |
| `↑` `←` `Shift+Space` `PageUp` | previous step |
| `Home` / `End` | first / last step |
| bottom bar (20 ticks) | click a tick to jump to that step |
| `#step-N` in the URL | opens directly at step N (e.g. `#step-13`) |
| `F` | full screen |
| `N` | speaker notes for the current step |
| `S` or `C` | sources + evidence drawer |
| `L` | map legend |
| `M` | grid of all 20 steps |
| `R` | restart at step 1 |
| `X` | reduced motion (drawings jump to their final state) |
| `Esc` | close any panel |

A burst of wheel events counts as one gesture. A new step needs at least 0.55 s and a short
pause in the wheel, so a fast flick can't skip several steps.
