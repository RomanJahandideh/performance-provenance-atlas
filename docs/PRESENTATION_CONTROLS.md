# Presentation Controls

The talk is **10 sheets and 36 scroll steps**. Each sheet is one board about one topic
(education, dissertation, awards, landscape, publications, prototypes, direction, fit,
questions). The first step of a sheet shows the whole board. Each next scroll zooms the board
to one part and fades the rest, while the column on the left explains that part.

| Input | Action |
|---|---|
| one wheel gesture, swipe or key press | one step |
| down, right, Space, PageDown | next step |
| up, left, Shift+Space, PageUp | previous step |
| Home / End | first / last step |
| bottom bar | ticks grouped by sheet; click one to jump |
| `#step-N` in the URL | open at step N |
| F | full screen |
| N | speaker notes |
| S or C | sources and evidence |
| M | list of all steps |
| R | restart |
| X | reduced motion |
| Esc | close any panel |

Speaking time: about 11 to 12 minutes of notes (see PRESENTATION_SCRIPT.md), so the talk
fits inside 20 minutes with pauses.
