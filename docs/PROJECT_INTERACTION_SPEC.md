# Project Interaction Spec

Every interaction exists to explain a relationship — cause/effect, rule→geometry,
geometry→evidence, or human↔AI handoff. Nothing autoplays while the presenter speaks; sequences
advance by key, click, or scroll, and every control has a keyboard path and a visible state.

## Global

| Interaction | Purpose |
|---|---|
| Scroll / arrows between scenes | Camera travels the atlas — the argument literally moves across one coherent territory; irrelevant layers drop to 17% opacity (low-information context) |
| Step dots + `NEXT →` in each panel | Progressive disclosure matched to the spoken script |
| Route drawing per scene | Shows where the presentation is on the intellectual trajectory; the current node pulses |
| Parcel click → project sheet | Question, inputs, process, evidence, honest limitation, GenEnv relevance, verified links — the per-project "board" without leaving the map |
| Legend (`L`) | Teaches the status drawing language in <20 s |
| Source drawer (`S`) | Claims + citations + verification notes for the current scene |
| Mini-map | Persistent position awareness; recentre in explore mode |
| Explore mode (`D`) | Free pan/zoom + status filters for Q&A detours |

## Scene-specific

**02 Trajectory** — campus territory rings highlight per step; award structures open board sheets
(image, award, year, context, source), connecting design/photography practice to spatial
communication rather than decoration.

**03 Foundation** — eCAADe chamber shows the warm/bright vs cool/dark pair with the measured
reversal annotated (depth contours = the judged axis); ISS halo animates HR→pulse/glow with a
numeric chip beside it, stating the 3.90 s result and the trust trade-off; BioTerrarium pipeline
animates watch→bridge→Unity with the <200 ms bound and a "conceptual visualization" label.

**04 PMG** — clicking a constraint row illuminates its setback/height plane on the envelope
(*rule → geometry*); the mode segment (simple lot / irregular / urban block) replays the
generality of one verified clipping method; the review stamp + representative history show the
independent check and non-destructive revision (*AI explains, code computes*).

**05 ZLA** — the three-stage pipeline animates flow; switching to the laneway case visibly
severs the pipeline after retrieval and stamps NOT COVERED (*refusal as observable behaviour*);
the site check draws the 10×37 plan with the inset arithmetic and extrudes 1→2 floors on the FSR
toggle (*deterministic arithmetic, model explains*).

**06 VCM** — the method slider crossfades flat-cap ↔ floor-by-floor massing under the real
rising ceiling while the floors/GFA annotation follows (*precision → recovered capacity*);
the rotation slider spins the footprint against the schematic GFA/floor-count chart
(*centroid explanation*); the evidence-state list keeps real/verified/placeholder/unexecuted
distinct in the drawing itself.

**07 EMA** — steps assemble the council (Generator → Critics → Orchestrator) with agent paths
animating only at the critique step (*proposal vs deterministic evaluation*); the search panel
shows 5+5 schematic seed tracks against the 95% threshold (labelled schematic; counts are the
repo's); the Pareto panel shows the 10-member r=−1.000 front; the verdict step pins the red
NOT CONFIRMED beside the supported reliability finding (*negative result as maturity*).

**08 Synthesis** — the chain assembles stage by stage with leader lines dropping to the parcels
that carry each stage (*four projects → one infrastructure*).

**09 PhD** — the provenance spine is clickable: each of the eight links opens an inspector
panel populated from the *real* corridor-study facts, labelled a conceptual demonstration
(*what the record would hold and why*); steps swap the right column between subquestions,
possible system, and possible methods — all marked provisional.

**10 Why GenEnv** — the territory stays visually external (double boundary, yellow foundations,
attribution lines); a dashed blue connector marks the proposed contribution *into* the funded
program (*alignment without ownership claims*).

**11 Conversation** — the camera returns to the full atlas: the proposal is visible as the
infrastructure latent in the earlier work; three questions invite the lab to shape it.

## Reliability rules

No live API calls; demos are scripted reconstructions from saved representative data with
"Open live system" links as secondary options (new tab, never iframes). All content reachable
without hover. Reduced motion (OS or `X`) collapses every animation to direct state changes with
identical content.
