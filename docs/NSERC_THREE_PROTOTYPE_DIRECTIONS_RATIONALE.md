# Three Possible Directions: Rationale

Why the deck now ends with three possible directions within one program instead of one fixed
proposal (2026-11-19, from `GenEnv_NSERC_Validated_PhD_Directions.pdf`).

## One program

All three belong to Xun Liu's 2026 NSERC Discovery program, **Human-AI Co-Design Framework for
Performance-Aware Constructed Environments**. The program title was verified on UBC Research's
announcement of 7 July 2026. The confidential proposal is not public, so nothing claims to follow
its work plan. Each direction would be one dissertation; they are not to be combined.

## What could not be the novelty

GenEnv and recent work already cover these, so the deck does not claim them:
- language to Grasshopper through MCP (Liu and Tian, NeurIPS 2025; GenEnv rhino-gh-mcp);
- adjustable permission modes (rhino-gh-mcp's Inspect, Tune, Coach, Execute, Author);
- specialist agents with simulation and a rationale log (Lam, ArchSim, UBC M.Arch 2026);
- text to CAD;
- agents that run building simulation;
- thermal optimisation;
- Grasshopper and VR round trips.

This is why the earlier "four agency levels" framework step was removed from the talk.

## The gap

Human-governed continuity of verified performance evidence across changing models and tools.
Performance provenance stays as the supporting record of each change, not the dissertation.
